# ZЯ — автопереключатель раскладки клавиатуры Windows

**ZЯ** (`zя`, `Zya`) — программа для Windows, которая пытается исправить типичные опечатки в раскладке клавиатуры: текст, набранный на английской раскладке, но намеренно или случайно попавший в русскую, и наоборот.

Проект написан на Rust. Основная цель — распознавать слова по смыслу и контексту, а не просто зеркально перекладывать символы.

## Что умеет

- Исправляет типичные опечатки раскладки:
  - `ghbdtn` → `привет`
  - `руддщ` → `hello`
  - `еру` → `the`
- Понимает `&` как границу слова, поэтому `Ghbdtn&` может исправляться.
- Исправляет кавычки:
  - `ЭприветЭ` → `"привет"`
  - `приветЭ` → `привет"`
  - `ЭЭЭ` → `"""`
  - `ЭруддщЭ` → `"hello"`
- Не портит обычные слова:
  - `Эта`
  - `Эра`
  - `Эхо`
- Работает с выделением через горячие клавиши:
  - `Break` — переключить раскладку выделения или последнего слова;
  - `Ctrl+Break` — сделать выделение/последнее слово в верхнем регистре;
  - `Shift+Break` — сменить регистр выделения или последнего слова.

## Установка

На обычном компьютере достаточно одной команды:

```powershell
irm https://raw.githubusercontent.com/demoonk/Zya/main/install.ps1 | iex
```

Если PowerShell ругается на policy:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/demoonk/Zya/main/install.ps1 | iex"
```

Если репозиторий уже скачан, можно так:

```powershell
.\install.ps1
```

Установщик сам:

- скачивает последнюю release-версию `z.exe` с GitHub (asset называется `z.exe`, локально он сохраняется как `zя.exe`);
- проверяет, запущен ли Punto Switcher;
- копирует программу в `%APPDATA%\zя\zя.exe`;
- создает `%APPDATA%\zя\config.json` и `%APPDATA%\zя\diario.log`;
- запускает `zя.exe` в фоне без параметров.

Запуск приложения без параметров:

```powershell
zя.exe
```

или двойной клик по `zя.exe`. Это сразу рабочий режим: ставится клавиатурный хук и появляется значок в трее. В релизе `zя.exe` — self-contained exe: сам создаёт `%APPDATA%\zя\` и `config.json`, а embedded-бинарь внутри него запускается как `run headless`.

Если Punto Switcher запущен, установщик предупредит о возможном конфликте. Чтобы закрыть его автоматически:

```powershell
.\install.ps1 -StopPunto
```

Если нужно собрать программу прямо на компьютере:

```powershell
.\install.ps1 -Build
```

Этот режим попытается скачать Rust через `rustup-init.exe`, а если `link.exe` отсутствует — скачать и установить Visual Studio Build Tools с workload **C++ build tools**.

Полезные ключи:

```powershell
.\install.ps1 -NoStart
.\install.ps1 -StopPunto
```

## Иконки в трее

Иконки сделаны крупными и прозрачными:

- белый текст на прозрачном фоне;
- буква `Я` для русской раскладки;
- буква `Z` для английской раскладки;
- значок занимает максимальную высоту 32×32 px;
- состояние автопереключения видно в всплывающей подсказке и меню значка.

В меню значка есть:

- `Исключить активное окно` — добавляет текущую программу в исключения;
- `Исключить папку активного окна` — добавляет папку программы в исключения;
- `Исключения` — список добавленных программ и папок;
- `Сбросить исключения` — очищает список.

То же можно задать из командной строки:

```powershell
zя.exe exclude add chrome.exe
zя.exe exclude add-dir C:\Games
zя.exe exclude list
```

Перегенерировать иконки можно скриптом:

```powershell
python abrakadabra/tools/build_tray_icons.py
```

## Удаление

```powershell
.\Uninstall.ps1
```

Чтобы сохранить настройки и журнал:

```powershell
.\Uninstall.ps1 -KeepSettings
```

## Структура проекта

- `abrakadabra/` — Rust-приложение.
- `data/` — языковые данные и корпуса для тестов.
- `install.ps1`, `install.bat`, `Uninstall.ps1`, `uninstall.bat` — установка и удаление.
- `INSTALL.md` — инструкция по установке.
- `build.ps1` — скрипт сборки.

## Текущее состояние
