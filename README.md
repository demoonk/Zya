# ZЯ — автопереключатель раскладки клавиатуры Windows

**ZЯ** (`zя`, `Zya`) — программа для Windows, которая пытается исправить типичные опечатки в раскладке клавиатуры: текст, набранный на английской раскладке, но намеренно или случайно попавший в русскую, и наоборот.

Проект написан на Rust. Основная цель — распознавать слова по смыслу и контексту, а не просто зеркально перекладывать символы.

## Что умеет

- Исправляет типичные опечатки раскладки:
  - `ghbdtn` → `привет`
  - `руддщ` → `hello`
  - `еру` → `the`
- Понимает `&` как границу слова, поэтому `Ghbdtn&` может исправляться.
- Исправляет кавычки:
  - `ЭприветЭ` → `"привет"`
  - `приветЭ` → `привет"`
  - `ЭЭЭ` → `"""`
  - `ЭруддщЭ` → `"hello"`
- Не портит обычные слова:
  - `Эта`
  - `Эра`
  - `Эхо`
- Работает с выделением через горячие клавиши:
  - `Break` — переключить раскладку выделения или последнего слова;
  - `Ctrl+Break` — сделать выделение/последнее слово в верхнем регистре;
  - `Shift+Break` — сменить регистр выделения или последнего слова;
  - `Alt` — отменить последнее исправление;
  - `Ctrl+Alt+P` — включить или выключить автопереключение.
- Горячие клавиши не зашиты намертво: в окне настроек клик по строке в таблице
  «Горячие клавиши» — нажать новую комбинацию, `Esc` или «Отмена» — закрыть,
  «Сбросить» — вернуть стандартные.

## Установка

Установщик `z.exe` требует прав администратора (манифест `requireAdministrator`).
Само приложение работает от обычного пользователя: клавиатурный хук и значок в трее
администратора не требуют.

На обычном компьютере достаточно одной команды:

```powershell
irm https://raw.githubusercontent.com/demoonk/Zya/main/install.ps1 | iex
```

Если PowerShell ругается на policy:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/demoonk/Zya/main/install.ps1 | iex"
```

Если репозиторий уже скачан, можно так:

```powershell
.\install.ps1
```

Установщик сам:

- скачивает последнюю release-версию `z.exe` с GitHub (asset называется `z.exe`, репозиторий `demoonk/Zya`);
- проверяет, запущен ли Punto Switcher;
- останавливает старые копии программы;
- кладет приложение в `%APPDATA%\zя\zя.exe`;
- создает `%APPDATA%\zя\config.json` и `%APPDATA%\zя\diario.log`, если их нет;
- добавляет автозапуск при входе (запись `zя.exe` в `HKCU\...\Run`);
- запускает `zя.exe run headless` — без окна консоли.

Рабочее приложение — `zя.exe` в `%APPDATA%\zя\`:

```powershell
zя.exe
```

или двойной клик по `zя.exe`. Это сразу рабочий режим: ставится клавиатурный хук и появляется RU/EN значок в трее. `z.exe` — это установщик: бинарь приложения embedded в него, при запуске он пишет `zя.exe` в `%APPDATA%\zя\`, создает `config.json` и `diario.log` и запускает приложение как `run headless`.

Если Punto Switcher запущен, установщик предупредит о возможном конфликте. Чтобы закрыть его автоматически:

```powershell
.\install.ps1 -StopPunto
```

Если нужно собрать программу прямо на компьютере:

```powershell
.\build.ps1
```

Скрипт проверяет, что `cargo` установлен, и собирает `abrakadabra` в release-режиме
(`-Debug` — debug-сборка). Если сборка падает с `linker link.exe not found`, нужны
Visual Studio Build Tools с workload **C++ build tools** — об этом скрипт пишет сам.

Полезные ключи:

```powershell
.\install.ps1 -NoStart
.\install.ps1 -StopPunto
```

## Окно настроек

Одно окно, слева три вкладки — вместо прежних отдельных диалогов:

- **«Настройки»** — карточка версии и кнопка «Проверить обновления» (она становится
  «Обновить», только когда на GitHub `demoonk/Zya` есть более свежий релиз с asset
  `z.exe`), чекбоксы «Автозапуск при входе» и «Запускать как администратор» и таблица
  горячих клавиш. Клик по строке открывает окно «Нажмите новую комбинацию»: нужно
  нажать сочетание клавиш, `Esc` или «Отмена» — закрыть без изменений. Кнопка
  «Сбросить» возвращает стандартные клавиши.
- **«Игнорировать»** — «Добавить из запущенных», «Добавить новый процесс»,
  «Удалить выбранное», поле фильтра и список исключённых процессов и папок. Правая
  кнопка мыши на строке: «Скопировать строку», «Скопировать весь список», «Удалить».
- **«Лог»** — цветные строки из `diario.log`, фильтр, кнопки «Обновить» и «Очистить»,
  то же контекстное меню копирования по правой кнопке мыши.

Окно само объясняет, почему комбинацию нельзя назначить: `alt` сам по себе занят
сменой раскладки, `ctrl`/`shift`/`win` без обычной клавиши — не комбинация, `break`
закреплён за undo (кроме строк, где он уже стоит), а `win+l`, `win+r`, `win+e`,
`win+i`, `win+a`, `win+tab`, `alt+f4`, `alt+tab`, `ctrl+shift+esc` и
`ctrl+alt+delete` заняты Windows.

Окно красится под тему Windows: тёмная тема — тёмное окно, светлая — светлое. Для
проверки тему можно задать переменной `ZYA_THEME=light` или `ZYA_THEME=dark`.

## Иконка в трее

Значок рисуется программой под текущую тему:

- `RU` для русской раскладки, `EN` для английской;
- фон прозрачный, подложки под буквами нет;
- в тёмной теме буквы белые, в светлой — чёрные;
- размер подбирается так, чтобы буквы заняли всю иконку 32×32 px;
- когда автопереключение выключено, поверх букв идёт красный косой штрих;
- состояние автопереключения видно в всплывающей подсказке и меню значка.

В меню значка (правый клик) есть:

- `Автоисправление раскладки` — включить или выключить автоисправление;
- `Автозапуск при входе` — запись `zя.exe` в `HKCU\...\Run`;
- `Настройки` — открыть окно настроек;
- `Выход`.

Левый клик по значку — включить или выключить автоисправление.

Иконка приложения — клавиша-кейкап (белая клавиша, чёрная `Z` и красная `Я`): она
встроена и в `z.exe`, и в `zя.exe` через `abrakadabra/build.rs` (файл
`abrakadabra/data/app.ico`).

Исключения можно добавить и из командной строки:

```powershell
zя.exe exclude add chrome.exe
zя.exe exclude add-dir C:\Games
zя.exe exclude list
```

Перегенерировать файл иконки приложения (`abrakadabra/data/app.ico`) можно
скриптом — сам значок в трее рисуется программой на лету:

```powershell
python abrakadabra/tools/build_tray_icons.py
```

## Удаление

```powershell
.\Uninstall.ps1
```

Чтобы сохранить настройки и журнал:

```powershell
.\Uninstall.ps1 -KeepSettings
```

## Структура проекта

- `abrakadabra/` — Rust-приложение: `src/main.rs` (CLI и рабочий режим),
  `src/settings_ui.rs` (окно настроек), `src/tray.rs` (значок в трее),
  `build.rs` (встраивает иконку и манифест в exe).
- `data/` — языковые данные и корпуса для тестов.
- `tools/zya_launcher.rs` — установщик `z.exe`, `tools/build_launcher.ps1` — его сборка.
- `install.ps1`, `install.bat`, `Uninstall.ps1`, `uninstall.bat` — установка и удаление.
- `INSTALL.md` — инструкция по установке.
- `build.ps1` — скрипт сборки.

## Текущее состояние

В исходниках уже добавлены обработки кавычек, `&` и более надежное `Shift+Break`,
новое окно настроек из трёх вкладок и значок в трее, который сам красится под тему
Windows. Для применения этих изменений нужно собрать проект через
`cargo build --release` (или через `.\build.ps1`).
