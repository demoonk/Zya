# Установка `z.exe`

## Быстрая установка

Требуется запуск от администратора.

Одна строка в PowerShell:

```powershell
irm https://raw.githubusercontent.com/demoonk/Zya/main/install.ps1 | iex
```

или из cmd:

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/demoonk/Zya/main/install.ps1 | iex"
```

Если репозиторий уже скачан:

```powershell
.\install.ps1
```

Установщик работает так:

1. Скачивает один self-contained файл с GitHub Releases: release asset называется `z.exe`, репозиторий `demoonk/Zya`.
2. Проверяет, запущен ли Punto Switcher.
3. Останавливает старую копию программы, если она уже запущена.
4. Кладет приложение в `%APPDATA%\zя\zя.exe`.
5. Создает `%APPDATA%\zя\config.json` и `diario.log`, если их нет.
6. Добавляет автозапуск при входе (запись `zя.exe` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
7. Запускает `zя.exe run headless`, то есть в рабочем режиме и без окна консоли.

`z.exe` — это установщик, ему нужны права администратора (манифест
`requireAdministrator`). Само приложение `zя.exe` работает от обычного пользователя:
хук и значок в трее администратора не требуют.

## Punto Switcher

Если Punto Switcher запущен, установщик предупредит об этом. Чтобы закрыть его автоматически:

```powershell
.\install.ps1 -StopPunto
```

## Запуск без параметров

После установки можно запустить:

```powershell
zя.exe
```

или просто двойной клик по `zя.exe` в `%APPDATA%\zя\`. Без параметров приложение сразу работает как `run headless`: ставится клавиатурный хук и появляется RU/EN значок в трее. `z.exe` — установщик: он заново кладет `zя.exe`, создает `config.json` и `diario.log` и запускает приложение в фоне.

## Окно настроек

Значок в трее -> правый клик -> `Настройки`. Окно с тремя вкладками:

- **Настройки** — версия и кнопка «Проверить обновления» (становится «Обновить»,
  когда на GitHub есть более свежий релиз), «Автозапуск при входе»,
  «Запускать как администратор» (задание `ZyaAutoStart` в Планировщике заданий с
  `/sc ONLOGON /rl HIGHEST`) и таблица горячих клавиш. Клик по строке — нажать новую
  комбинацию, `Esc` или «Отмена» — закрыть, «Сбросить» — вернуть стандартные.
- **Игнорировать** — «Добавить из запущенных», «Добавить новый процесс»,
  «Удалить выбранное», фильтр и список исключённых процессов и папок. Правая кнопка
  мыши на строке: «Скопировать строку», «Скопировать весь список», «Удалить».
- **Лог** — цветные строки из `diario.log`, фильтр, «Обновить» и «Очистить».

Окно подстраивается под тему Windows (тёмная — тёмное окно, светлая — светлое).
Тему можно задать вручную для проверки: `ZYA_THEME=light` или `ZYA_THEME=dark`.

По-прежнему доступны команды из командной строки:

```powershell
zя.exe settings
zя.exe exclude add chrome.exe
zя.exe exclude list
```

## Полезные ключи

```powershell
.\install.ps1 -NoStart
```
Установить, но не запускать.

```powershell
.\install.ps1 -StopPunto
```
Закрывает Punto Switcher перед установкой.

## Иконки

Трейный значок рисуется под текущую тему:

- прозрачный фон, подложки под буквами нет;
- буквы `RU`/`EN` на всю иконку 32×32 px;
- белые буквы в тёмной теме, чёрные в светлой;
- красный косой штрих поверх букв, когда автопереключение выключено.

В меню значка есть:

- `Автосправление раскладки`;
- `Автозапуск при входе`;
- `Настройки`;
- `Выход`.

Иконка самого приложения — клавиша-кейкап: белая клавиша, чёрная `Z` и красная `Я`.

## Удаление

```powershell
.\Uninstall.ps1
```

или:

```text
uninstall.bat
```

Чтобы оставить настройки и журнал:

```powershell
.\Uninstall.ps1 -KeepSettings
```
