# zя 0.2.0 — заметки к выпуску

## Исправлено: буфер обмена
- Все обращения к буферу обмена идут через один `clip_lock()` / `open_clipboard()`: пять
  попыток открытия окна, повторная попытка чтения, освобождение GMEM-блока при
  неудачной записи (раньше блок утекал).
- `ClipboardGesture` — RAII-страж: жест владеет буфером, пока не закончит. Авто-
  переписка (`tg.rs`, `composer_text`) и жест выделения больше не лезут в буфер
  одновременно. В `hook_proc` стоит guard: пока жест идёт, хук пропускает клавиши
  и не мешает Ctrl+C/Ctrl+V.
- Маркер-сентинел пишется только если запись реально прошла; вставка transformed
  текста выполняется только при успешной записи; чужое содержимое буфера
  восстанавливается лишь тогда, когда в буфере найден sentinel — текстовые форматы
  не затираются.
- Гонка WM_PASTE после Ctrl+V: жёсткий сон 250 мс заменён адаптивным опросом
  (до 900 мс, шаг 60 мс), который выходит, как только буфер изменился.
- Тесты: `the_clipboard_round_trip_restores_what_the_user_had`,
  `a_failed_clipboard_write_is_reported`,
  `only_one_gesture_owns_the_clipboard_at_a_time`.

## Исправлено: журнал
- «Очистить лог» больше не выглядит бездействующим: очистка инвалидирует кэш
  строк (`bump_rows()`), пишет пустой `diario.log` и `diario.log.1`, обнуляет
  счётчик и перерисовывает окно.
- Страница «Лог» читала дневник только при создании окна. Добавлен таймер
  `LOG_TIMER` (2 с): если размер `diario.log` изменился, список пополняется сам.
- Статус-строка больше не затирается каждые две секунды: автоматическое
  обновление заполняет список, но не пишет сообщение в статус.

## Интерфейс
- Курсор в текстовых полях: `Edit` создаётся внутри нарисованной карточки
  (отступ 8 design-px, вертикальное центрирование по высоте строки, `WS_BORDER`
  убран) — каретка и текст теперь по центру рамки.
- Списки «Игнорировать» и «Словарь» отсортированы по алфавиту
  (`sort_rows_by_name`, регистронезависимо). Порядок в `config.json` не меняется:
  сортировка только отображаемая, удаление работает по значению строки.
- Шрифт переведён с `ANTIALIASED_QUALITY` на `CLEARTYPE_NATURAL_QUALITY`
  (замер advance'ов Segoe UI 10 pt @ 146 DPI: 229 px во всех режимах).
- Кнопка «Добавить активное приложение» теперь открывает меню открытых окон:
  `EnumWindows` без explorer.exe и без самого движка, дедупликация по процессу,
  сортировка «процесс → заголовок». На время меню клавиатурный хук снимается и
  ставится обратно. Есть CLI-проверка `zя.exe windows`.
- Удалены кнопки «Добавить новый процесс» и верхняя «Удалить выбранное».
- Добавлены подпись «Добавить», поле ввода и кнопка «Добавить», а также кнопка
  «Указать на диске» с фильтром «Процессы (*.exe)» / «Папки и файлы».
- Контекстное меню при множественном выделении: пункт «Удалить выбранное»
  удаляет все выделенные строки. Исправлена ошибка `LVM_SETITEMSTATE` (флаги
  передавались вместо указателя на `LVITEMW`).

- `zя deletetest multi`: 52 → 49 записей, все три строки удалены, конфиг

- Снимки вкладок: отсортированный список игнора, словарь по алфавиту, журнал с
